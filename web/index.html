Algorithm Overview

Needleman-Wunsch with CUDA Wavefront Parallelism

🔄 Recurrence

dp[i][j] = max(
  dp[i-1][j-1] + score(s1[i], s2[j]),
  dp[i-1][j] + gap,
  dp[i][j-1] + gap
)

⚡ Wavefront Key Insight

All cells on the same anti-diagonal (i+j = constant) are independent — they can be computed in parallel. Each diagonal is one CUDA kernel launch.

🏗️ CUDA Architecture

One thread per cell on the anti-diagonal. cudaDeviceSynchronize() between diagonals acts as a global barrier — identical to this dashboard's animation steps.
